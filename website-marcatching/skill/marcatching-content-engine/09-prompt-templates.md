# 09 — Prompt Templates

## Default Final Production Prompt

```text
/marcatching-content-engine
Bikin carousel Marcatching 4 slide 4:5 tentang [topik]. Output final image slides only dan 1 caption. Wajib kirim 4 image terpisah, bukan digabung dalam 1 grid. Gunakan data paling terbaru yang tersedia saat ini. Gunakan style benchmark Marcatching: dark theme, minimalis, premium editorial, dua font ala DM Sans dan Palatino, logo Marcatching kiri atas, icon kanan atas, body copy readable, tidak terlalu banyak text, visual realistis dan supporting UI elements seperlunya. Slide 1 cukup 1 headline hook saja tanpa body copy kecil. Jangan tampilkan research, hook options, score, atau design brief.
```

## Short Prompt

```text
/marcatching-content-engine
Bikin carousel Marcatching 4 slide 4:5 tentang [topik]. Output final image slides only dan 1 caption. Wajib 4 image terpisah, bukan 1 grid. Pakai data terbaru, dark theme, minimalis, premium editorial, logo kiri atas, icon kanan atas, slide 1 cukup headline saja.
```

## Strict Add-on

```text
Jangan pakai light theme. Jangan pakai neon glow. Jangan terlalu banyak warna. Jangan terlalu banyak card, chart, atau icon. Maksimal 1 accent color muted blue. Pertahankan dark minimalist editorial look.
```
