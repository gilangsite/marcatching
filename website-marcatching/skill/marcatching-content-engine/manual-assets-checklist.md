# Manual Assets Checklist

## Add benchmarks
Put preferred visual references into:
- `assets/benchmarks/`

## Add logos
Put official Marcatching logo files into:
- `assets/logos/`

Recommended names:
- `marcatching-logo-primary.png`
- `marcatching-logo-primary.svg`
- `marcatching-logo-icon.png`
- `marcatching-logo-icon.svg`

## QC reminder
Reject outputs if they are:
- light theme without request
- too colorful
- too glowing
- too crowded
- body copy too small
- not using Marcatching two-font feel
