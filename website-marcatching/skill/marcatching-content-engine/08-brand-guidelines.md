# 08 — Marcatching Brand Guidelines

## Brand Essence

Marcatching is a premium marketing intelligence brand that explains business, technology, AI, economy, brand strategy, and consumer psychology with sharp, simple, strategic content.

## Visual Identity

Default visual style:
- dark theme
- black or near-black background
- white/off-white typography
- minimal gray secondary text
- one muted blue accent when needed
- premium editorial composition
- realistic imagery
- clean negative space

## What Marcatching is not

Marcatching is not:
- colorful SaaS dashboard content
- neon cyberpunk content
- generic business infographic
- childish icon content
- loud motivational quote content
- crowded template design
- rainbow glow design

## Typography

Use two-font contrast:
- modern sans for clarity
- elegant serif for premium editorial emphasis

Typography must feel stable across slides.
Body copy must be readable on mobile.

## Logo Placement

Every slide:
- creator's own wordmark/brand name top-left (from `brand-memory.md`'s `Brand/Creator:` line — never hardcode "Marcatching")
- creator's own icon/monogram top-right

Keep placement subtle and consistent; only the identity shown changes per creator.

## Cover Rule

For slide 1, default to:
- one main hook headline only
- no extra paragraph body copy unless explicitly requested
- one strong visual support only

## Visual Modules

Use modules only when they clarify the idea.

Good modules:
- rounded box
- subtle card
- simple chart
- screenshot-like UI
- highlight effect
- small company/app logo

Bad modules:
- too many cards
- too many colors
- glowing icon clusters
- crowded dashboards

## Final Brand Standard

The final carousel should look:
- premium
- minimal
- dark
- readable
- strategic
- current
- calm
