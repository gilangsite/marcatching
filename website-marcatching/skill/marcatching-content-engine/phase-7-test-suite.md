# Phase 7 Test Suite

## Purpose

This file contains ready-to-use test prompts for validating the Marcatching Content Engine.

Use these tests in a fresh ChatGPT conversation with the latest engine zip or extracted files uploaded.

---

## Test 1 — Business Model Breakdown

```text
/marcatching-content-engine
Mode: Phase 7 Full Test
Segment: Business Model Breakdown
Topic: Darimana OpenAI dapat uang?
Output: full package
Quality Rule: If Content Doctor score is below 80, rewrite before design. If Design QC score is below 80, provide regeneration instructions.
```

Expected quality:
- revenue explanation is simple but strategic
- no outdated financial claims without research
- hook has strong curiosity
- design brief feels tech-business editorial
