# 12 — Slide Family System

## Purpose

This file defines the approved slide families for a minimal dark Marcatching carousel.

## Global rules

- 4:5 vertical carousel
- dark theme default
- creator's own wordmark/brand name top-left (from `brand-memory.md`, never hardcode "Marcatching")
- creator's own icon/monogram top-right
- one accent color maximum
- body copy readable
- minimal visual modules
- consistent type scale across slides
- final delivery must be separate image files, not one grid

## Family A — Minimal Hero Cover

Use for slide 1.

Structure:
- logo top-left
- icon top-right
- big hook headline only
- no paragraph body copy by default
- one hero image or product/UI visual
- no dense cards

Best for:
- opening question
- sharp business claim
- founder/company hook

## Family B — Text Top, Visual Bottom

Structure:
- headline top
- body copy below headline
- visual support below
- maximum 1 to 2 modules

Best for:
- explaining one revenue source
- showing one app/product system

## Family C — Visual Top, Text Bottom

Structure:
- large visual top
- headline below
- body copy below
- optional one highlight line

Best for:
- app screenshots
- realistic product or office scene
- founder image

## Family D — Minimal Breakdown

Structure:
- headline
- 2 or 3 cards maximum
- simple dividers
- one restrained chart or percentage if needed

Best for:
- summary of sources
- 3-part framework
- revenue layers

## Family E — Reframe / Closing

Structure:
- one strong final statement
- short explanation
- CTA or follow line
- minimal brand footer

Best for:
- last slide
- conclusion

## Default 4-slide rhythm

1. Family A
2. Family B
3. Family C or D
4. Family E

## Variation rule

Do not lock every slide to the same left-text right-image composition.
Use calm variation across the set so the carousel feels premium and not templated.
