# Marcatching Benchmark Notes

## Approved Direction

The approved direction is not colorful dashboard design. It is dark minimalist editorial business design.

## Must Preserve

- dark background
- clean top-left wordmark/brand name (creator's own, from `brand-memory.md`)
- top-right icon/monogram (creator's own)
- refined two-font contrast
- readable body copy
- simple visual modules
- realistic image support when useful
- calm premium mood

## Must Avoid

- light theme unless requested
- neon glow
- rainbow gradients
- too many colors
- too many app icons
- too many cards
- crowded dashboard layout
- tiny body copy
- inconsistent headline scale

## Ideal Slide Feel

The slide should feel like a premium business magazine cover mixed with clean tech editorial design.

## Body Copy Note

Body copy should be slightly larger than previous outputs so viewers do not skip it. It should be readable on mobile without becoming as dominant as the headline.

## Accent Color Note

Use only one accent color. Muted Marcatching blue is preferred.

## Supporting Visual Note

Use support visuals to clarify, not to decorate.
Good supporting visuals: one rounded card, one app screen, one product scene, one subtle chart, one highlight.
