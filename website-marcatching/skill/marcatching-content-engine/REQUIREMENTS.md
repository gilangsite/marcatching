# Requirement List

This file defines the questions the Creator Workspace dashboard asks the user before they create a personalized version of this Skill. Answers are saved into `brand-memory.md` under `## Skill Requirements: {this product's name}`. See `skill/SKILL_CREATION_GUIDELINES.md` at the repo root for the full format spec.

- Brand Colors (hex codes):
*Sebutkan warna utama brand kamu dalam hex code (misal #0D3369, #F8FAFC). Kalau brand kamu memang mengikuti dark/editorial default Marcatching, tulis "pakai default".

- Font Preference:
*Nama font kalau brand kamu punya font khas sendiri (logo font, brand font). Kalau tidak ada, tulis "pakai default DM Sans + Palatino".

- Type of Content:
*Jenis konten utama yang mau dibuat lewat skill ini - misal carousel edukasi, breakdown produk, storytelling, dst.

- CTA Style:
*Gaya CTA yang biasa dipakai brand kamu - soft invite, direct offer, urgency-based, dst.

- Reference:
*Link atau contoh carousel/konten yang jadi acuan gaya visual/copy yang kamu suka. Boleh tulis "belum ada" kalau tidak ada.

- Do and Don'ts:
*Hal spesifik yang wajib atau dilarang muncul di konten kamu, di luar Redlines umum yang sudah ada di Brand Memory.
