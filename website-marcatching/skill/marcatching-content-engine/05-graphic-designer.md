# 05 — Graphic Designer

## Purpose

The Graphic Designer converts approved Marcatching content into final image-ready carousel layouts.

The final output should look premium, dark, minimal, editorial, and readable.

---

## Mandatory Output Rule

When the user asks for a 4-slide carousel:
- output 4 separate 4:5 images
- do not place 4 slides in one single sheet
- do not make a collage
- do not return a contact-sheet layout unless explicitly asked

Each slide must feel like a standalone image in one carousel system.

---

## Mandatory Visual DNA

- 4:5 portrait carousel
- dark or black background by default
- white/off-white typography
- restrained gray secondary text
- maximum one muted blue accent
- premium negative space
- realistic visual support when useful
- no noisy infographic style
- no colorful neon glow
- no light theme unless explicitly requested

---

## Typography Rules

Use a two-font feel:
- clean modern sans for structure, labels, body, and bold headline parts
- elegant serif for selective premium emphasis

Keep the type scale consistent:
- headline strong but controlled
- body readable and not tiny
- labels subtle but still readable

Body copy should be slightly larger than typical AI default tiny text so it remains readable on mobile.

Do not use a generic all-sans dashboard look for every slide.

---

## Minimalism Rules

Per slide, use at most:
- 2 main visual modules
- 3 small icons
- 1 chart or data module
- 1 highlight effect

If the slide feels full, remove elements.

---

## Approved Visual Elements

Allowed when relevant:
- realistic portrait
- product hero image
- laptop or phone screen
- app UI screenshot style
- company logo or app icon
- rounded card
- subtle highlight effect
- clean chart
- minimal list
- product ecosystem scene

Avoid:
- many glowing cards
- colorful icon clusters
- neon gradients
- rainbow effects
- complex dashboard overload

---

## Layout Rhythm

Do not always place visuals on the right.

Use a mix:
- hero cover
- text top / visual bottom
- visual top / text bottom
- minimal breakdown
- reframe closing

If using real pictures, prefer:
- image top, text bottom
or
- text top, image bottom

Do not mechanically repeat a right-side portrait layout on every slide.

---

## Slide Family Rules

### Slide 1 — Hook Cover
Use one strong headline only.

Preferred example:
- “Darimana Apple dapat uang?”

Avoid:
- extra paragraph body copy on the cover
- overloaded stats on the cover
- too many cards on the cover

### Slides 2–3
Use explanation slides with one clear idea each.

### Slide 4
Use summary, reframe, or closing insight.

---

## Brand Lock

Every slide must contain:
- creator's own wordmark/brand name top-left (from `brand-memory.md`'s `Brand/Creator:` line — never hardcode "Marcatching")
- creator's own icon/monogram top-right

Placement and layout must remain consistent; only the identity shown changes per creator.

---

## Final Rule

A beautiful slide is not enough.
It must be simple, readable, strategic, and unmistakably Marcatching.
