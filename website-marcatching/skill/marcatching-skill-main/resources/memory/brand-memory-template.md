# Brand Memory Template

This is the blank form to fill only when `brand-memory.md` does not already exist at the skill root (see SKILL.md → Setup Memory Compatibility, Path B). If you were issued this Skill personalized from the Marcatching website, `brand-memory.md` already exists and is already filled — you do not need this template.

Fill this using the exact schema below, then save the filled version as `brand-memory-profile.md` (see README.md for the full manual setup flow):

```markdown
# Brand Memory
Brand/Creator:

## Creator Voice
Describe sentence rhythm, word choice, formality, energy, humor, point of view, and 2-3 example sentences that sound right. Also name styles that look similar but are NOT this brand's voice.

## Redlines
Claims that must never be made, sensitive topics, words to avoid, urgency tactics that are forbidden, legal/ethical rules, and behavior that would break audience trust.

## Audience Facts
What is already known from DMs, comments, interviews, transactions, or observation — not assumptions still to be tested. Include the audience's own language, buying conditions, objections, and recurring patterns.

## Output Quality Gate
The minimum bar for a usable output: required specificity, required proof, structure, CTA, length, language quality, and signs that an output must be rewritten.

## Experiment Learnings
Signals from past content/campaign experiments worth reusing as a hypothesis for the next output. Optional — leave as "Belum ada experiment learning yang diimpor." if none yet.
```
