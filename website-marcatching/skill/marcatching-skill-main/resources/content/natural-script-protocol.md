# Natural Script Protocol

Use for TikTok, Reels, Shorts, UGC, skits, explainers, and talking-head scripts.

## Script Must Pass 5 Tests

### 1. Read-Aloud Test
Would a real human say this?

Remove lines that sound like an article.

### 2. Breath Test
Can the creator say the sentence without running out of breath?

Shorten long lines.

### 3. First-Second Test
Does the first line create tension, curiosity, or recognition?

### 4. Retention Test
Does every 2-4 seconds give a new reason to keep watching?

### 5. Payoff Test
Does the ending resolve the promise from the hook?

## Avoid

```text
Pada video kali ini...
Di era digital saat ini...
Seperti yang kita ketahui...
Yuk simak sampai akhir...
Berikut adalah...
```

## Better Openings

```text
Masalahnya bukan kamu kurang rajin posting.
Ini alasan kenapa konten edukasi sering gagal FYP.
Kalau script kamu terdengar terlalu rapi, justru orang skip.
Banyak brand salah paham soal AI marketing.
```
