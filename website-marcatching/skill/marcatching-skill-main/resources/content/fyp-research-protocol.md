# FYP Research Protocol

## If Browsing Is Available

Research in this order:

1. Platform-native search results or examples provided by user
2. Competitor accounts
3. Official brand/product sources
4. Creator comments and audience language
5. Reputable industry sources for factual context

## If Browsing Is Not Available

Ask user for:

```text
3-10 content links
screenshots
captions/scripts
analytics
comments
competitor examples
```

## Viral Pattern Extraction

Do not say “it went viral because it was interesting.”

Extract:

```text
Hook mechanic:
First-frame pattern:
Pacing:
Emotional trigger:
Audience identity:
Share/save trigger:
Comment trigger:
Format:
Timing:
Repeatable formula:
```

## Risk

Do not recommend copying competitor content.

Adapt mechanics, not surface wording.
