# Viral Potential Preflight

Use this before creating content that is expected to be viral, FYP-friendly, high-reach, shareable, or scroll-stopping.

## When To Use

Use when the user mentions:

- FYP
- viral
- reach
- views
- engagement
- share
- save
- scroll-stopping
- TikTok
- Reels
- Shorts
- "konten yang rame"
- "konten yang berpotensi viral"

## Mandatory Analysis Before Writing

```text
Platform behavior:
Audience trigger:
Core tension:
Pattern interrupt:
Hook hypothesis:
Retention mechanism:
Share/save reason:
Originality angle:
Proof/source need:
FYP risk:
```

## Viral Readiness Score

Score before writing:

```text
Audience Relevance:
Hook Strength:
Tension:
Originality:
Platform Fit:
Retention Logic:
Share/Save Trigger:
Brand Fit:
Fact Safety:
Production Feasibility:
```

If any of these are below 8/10, do not write final content yet. Improve the angle first.

## Common Reasons Content Fails

- It is an article disguised as social content.
- It has no platform-specific format.
- It starts with explanation instead of tension.
- It uses a topic that is already crowded without a new angle.
- It has save value but no share identity.
- It has a useful checklist but no emotional trigger.
- It has no first 2-second pattern interrupt.
- It does not define the audience sharply.

## Required Output Before Draft

Before writing final content, create:

```text
Viral Hypothesis:
Why audience would stop:
Why audience would continue:
Why audience would save/share:
Why this angle is not generic:
Main failure risk:
Improvement before writing:
```
