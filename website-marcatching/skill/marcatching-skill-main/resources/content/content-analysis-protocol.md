# Content Analysis Protocol

Use to analyze why content FYP, underperformed, or needs improvement.

## Do Not Be Shallow

Avoid:

```text
Because the content is interesting.
Because the hook is good.
Because the topic is relevant.
```

Instead diagnose:

```text
Hook clarity:
First-frame strength:
Audience recognition:
Emotional trigger:
Retention devices:
Payoff:
Share trigger:
Save trigger:
Comment trigger:
Platform fit:
Timing:
```

## FYP Analysis Output

```text
Viral diagnosis:
Hook analysis:
Retention mechanics:
Emotional trigger:
Share/save trigger:
Why audience cared:
Repeatable formula:
Derivative ideas:
```

## Flop Analysis Output

```text
Performance diagnosis:
Hook weakness:
Retention risk:
Audience mismatch:
Format problem:
CTA problem:
Rewrite strategy:
New version:
```
