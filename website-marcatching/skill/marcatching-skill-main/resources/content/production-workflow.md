# Production Workflow

Use for calendars, SOPs, batching, teams, and repurposing.

## Content Batch Workflow

```text
Research
→ Idea selection
→ Script/copy
→ Fact safety
→ Design/record
→ Edit
→ Approval
→ Schedule
→ Publish
→ Review
→ Iterate
```

## Repurposing Rule

Do not repost the same asset everywhere.

Adapt by platform:

```text
TikTok/Reels: hook + retention + spoken script
Carousel: one idea per slide
LinkedIn: insight + story + strategic takeaway
X: compressed idea + sharp statement
Newsletter: context + deeper explanation
```
