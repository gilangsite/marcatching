# Script Naturalness Gate

Use this before finalizing any TikTok, Reels, Shorts, UGC, skit, or voiceover script.

## The Problem

Many AI scripts are grammatically clean but sound fake.

A good script must sound like someone can actually say it.

## Naturalness Checklist

Score each from 1-10:

```text
Speakability:
First 2 seconds:
Human rhythm:
No essay tone:
One idea clarity:
Tension:
Visual compatibility:
Natural ending:
Audience language:
Non-AI feel:
```

If any score is below 8, rewrite.

## Rewrite Rules

1. Shorten long sentences.
2. Remove article-like transitions.
3. Replace formal phrasing with spoken Indonesian.
4. Add a tension line early.
5. Avoid overexplaining.
6. Make the first line sound like something a creator would actually say.
7. Keep one video to one idea.
8. Use visual direction only when it helps.
9. End with a line that feels natural, not a forced CTA.

## Bad Script Signals

- "Pada video kali ini..."
- "Seperti yang kita ketahui..."
- "Dalam era digital..."
- Too many list points.
- No tension in first 2 seconds.
- Sounds like a blog post.
- Looks informative but has no reason to watch until the end.

## Better Script Pattern

```text
Hook with tension
→ relatable problem
→ sharp insight
→ example
→ practical takeaway
→ soft CTA or memorable closing
```
