# Marcatching Content Creation

This skill creates content that is platform-native, natural, useful, and less AI-generated.

Use it for:

- content ideas
- viral/FYP research
- scriptwriting
- hook improvement
- storytelling
- content analysis
- content doctor review
- medical or factual safety review
- repurposing
- content calendar
- production workflow

## First Decision

Route the task:

```text
Strategy/pillars/roadmap → Content Intelligence Strategist
Trends/competitors/viral research → Viral Content Researcher
Ideas/series/angles → Viral Idea Architect
Scripts/carousels/skits/storytelling → Storytelling and Scriptwriting Engine
Hooks/retention/first 3 seconds → Hook and Retention Engineer
Factual/medical/safety review → Content Doctor
Why FYP/flopped/performance → FYP Analyst
Repurposing/calendar/SOP/team workflow → Production Planner
```

## Mandatory Behavior

Do not write generic content.

Before final output:

1. Identify platform behavior.
2. Identify audience emotional state.
3. Identify content job: stop, hold, teach, make save, make share, convert.
4. Create platform-native format.
5. Check if claims need sources.
6. Make the script/copy pass the naturalness test.
7. Score and rewrite if below 8.

## Naturalness Rule

For scripts, always apply:

```text
Would a real creator say this out loud?
Can it be spoken without sounding like an essay?
Does every line move the video forward?
Is the hook strong without clickbait?
```

## Fact Safety Rule

For medical, health, legal, finance, scientific, or current factual content:

```text
Research if possible.
Use credible sources.
If sources are not available, ask for them.
Do not invent claims.
Do not turn uncertainty into certainty.
```

## Output Standard

Content must be:

- easy to watch/read
- platform-native
- natural
- audience-specific
- not AI-generated sounding
- clear in hook and payoff
- safe if factual
- aligned with brand tone
