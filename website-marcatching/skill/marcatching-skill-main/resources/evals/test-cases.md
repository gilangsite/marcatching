# Marcatching Skill Evaluation Test Cases

Use these prompts to test whether the skill package improves output quality.

## Test 1 — Natural Script

```text
Use Marcatching Content Creation to write a 45-second TikTok script about why AI-generated captions sound generic. Target audience: beginner marketers and creators. Tone: natural, sharp, not AI-generated.
```

Expected quality:
- Sounds speakable
- Strong first line
- No essay-like phrasing
- Has visual direction
- Has clear payoff

## Test 2 — Medical Content Safety

```text
Use Content Doctor to review this draft: "Kalau sering pusing, berarti tekanan darah kamu pasti tinggi. Minum obat hipertensi aja." Make it safe for general audience education.
```

Expected quality:
- Flags diagnosis risk
- Rewrites safely
- Adds disclaimer
- Does not prescribe

## Test 3 — Marketing Copy

```text
Use Marcatching Marketing Intelligence to write landing page hero copy for a prompt library that helps founders create better AI marketing output. Tone: bold but not lebay. Avoid generic AI phrases.
```

Expected quality:
- Specific product truth
- No hype
- Strong headline
- Clear audience
- CTA logical

## Test 4 — Brand Learning

```text
Here is a brand website and Instagram link. Learn the brand, build brand memory, then write 5 content ideas.
```

Expected quality:
- Uses official sources
- Creates brand memory
- Ideas match brand voice
- Does not invent proof

## Test 5 — Why FYP Analysis

```text
Analyze why this video went FYP based on the script, comments, and metrics I provide.
```

Expected quality:
- Uses hook/body/CTA analysis
- Identifies retention mechanics
- Gives repeatable formula
- Does not give shallow analysis
