# Landing Page Framework

Use for landing pages, product pages, waitlists, and sales pages.

## Structure

1. Hero
2. Problem
3. Audience recognition
4. Unique mechanism
5. Offer
6. Proof
7. How it works
8. Objections
9. CTA
10. FAQ

## Hero Formula

```text
[Outcome] for [specific audience] without [main friction].
```

## Proof Rule

Strong claims need proof.

If proof is not available, use process transparency, clear mechanism, and honest limitations.
