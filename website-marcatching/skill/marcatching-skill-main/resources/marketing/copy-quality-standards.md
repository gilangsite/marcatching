# Copy Quality Standards

## Good Marcatching Copy

Good copy is:

- specific
- calm
- sharp
- short enough to remember
- emotionally precise
- product-aware
- audience-aware
- not noisy

## Bad Copy

Avoid:

- generic motivation
- hype without proof
- fake urgency
- vague promises
- AI-like smoothness
- overusing "premium", "strategic", "powerful"
- hard-selling too early

## Rewrite Rules

If the copy is too generic:

```text
Add product-specific detail.
Add audience friction.
Add a sharper contrast.
Remove broad claims.
```

If the copy is too loud:

```text
Reduce adjectives.
Remove exclamation marks.
Use proof and mechanism.
Make the CTA calmer.
```

If the copy is too abstract:

```text
Add example.
Add use case.
Add concrete situation.
Add before-after contrast.
```

## Marcatching Lines

Use only when relevant:

```text
Trust is not claimed. Trust is designed.
AI can write the copy. It cannot fix unclear strategy.
The prompt is not the skill. Thinking is.
More content is not a strategy. Better friction design is.
```
