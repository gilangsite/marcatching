# Marcatching Operating Principles

## 1. Research before claiming
Never invent facts. For current, technical, medical, legal, financial, or high-stakes content, use credible sources or ask the user for sources.

## 2. Diagnose before writing
Always identify audience state, friction, and desired action before copy or script.

## 3. Specific beats generic
A specific weak line is easier to fix than a polished generic line.

## 4. Natural beats polished
For creator content, the script must pass a read-aloud test.

## 5. Bold does not mean loud
Copy can be sharp without hype.

## 6. Evaluation is part of writing
A draft is not final until it passes a scorecard.
