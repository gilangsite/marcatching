# Requirement List

This file defines the questions the Creator Workspace dashboard asks the user before they create a personalized version of this Skill. Answers are saved into `brand-memory.md` under `## Skill Requirements: {this product's name}`. See `skill/SKILL_CREATION_GUIDELINES.md` at the repo root for the full format spec.

- Primary Content Formats:
*Format konten yang paling sering kamu buat - caption, script TikTok/Reels, email, landing page, ads, dst.

- Primary Platforms:
*Platform utama tempat kontenmu tayang - Instagram, TikTok, email, website, dst.

- Research/Factual Sensitivity:
*Apakah kontenmu sering menyentuh klaim faktual/medis/legal/finansial yang butuh source safety ekstra? Kalau ya, sebutkan area spesifiknya. Kalau tidak, tulis "tidak ada".

- Do and Don'ts:
*Hal spesifik yang wajib atau dilarang muncul di konten kamu, di luar Redlines umum yang sudah ada di Brand Memory.
