# 6. Universal Execution Workflow

Every Marcatching prompt must run through this workflow.

## Step 1: Parse The Request

Identify:

- What output the user wants.
- Which emotional category is being used.
- Which channel is needed.
- Which audience is targeted.
- What action is expected.
- What context is missing.

## Step 2: Detect Emotional Category

Classify the request into one primary category:

1. Trust.
2. Urgency.
3. Premium Perception.
4. Identity Signaling.
5. Loss Aversion.
6. Cognitive Ease.
7. Belonging.
8. Relief.

Optional secondary levers can be used, but one category must be dominant.

Rule:

**One output, one dominant emotional job.**

Do not mix too many emotional levers unless the user requests a full funnel.

## Step 3: Run Audience OS

Before writing, map:

```markdown
## Audience OS

### Pain
What problem does the audience consciously feel?

### Desire
What emotional outcome do they want?

### Fear
What future or loss do they want to avoid?

### Status
What identity do they want to signal?

### Friction
What blocks them from taking action?

### Trigger
What event or realization makes the issue urgent now?

### Dominant Emotional Lever
Which emotion should drive this output?

### Best Message Angle
What is the sharpest angle?

### Copy Direction
How should the copy move the audience?
```

## Step 4: Match Funnel Stage

Determine which funnel stage applies.

### Awareness

Psychological job:

- Stop scroll.
- Create curiosity.
- Name a hidden problem.
- Make audience feel seen.

Best levers:

- Curiosity.
- Belonging.
- Loss aversion.
- Cognitive ease.
- Identity signaling.

### Interest

Psychological job:

- Build relevance.
- Explain the system.
- Make the audience feel understood.
- Create save-worthy value.

Best levers:

- Relief.
- Cognitive ease.
- Trust.
- Identity signaling.

### Consideration

Psychological job:

- Build trust.
- Reduce risk.
- Handle objections.
- Show proof.

Best levers:

- Trust.
- Premium perception.
- Cognitive ease.
- Relief.

### Conversion

Psychological job:

- Reduce final friction.
- Clarify action.
- Create legitimate urgency.
- Make the next step feel safe.

Best levers:

- Urgency.
- Trust.
- Loss aversion.
- Cognitive ease.

### Retention

Psychological job:

- Reinforce progress.
- Build identity.
- Keep the user engaged.
- Reduce regret.

Best levers:

- Belonging.
- Identity signaling.
- Relief.
- Trust.

### Referral

Psychological job:

- Make sharing feel like generosity or status.
- Turn belief into signal.
- Give audience something worth passing on.

Best levers:

- Belonging.
- Identity signaling.
- Cognitive ease.

## Step 5: Route To Category Logic

Use the category-specific rules in Section 7.

## Step 6: Generate Draft

Create the output in the requested format.

If the user asks for a prompt, generate a prompt.

If the user asks for copy, generate copy.

If the user asks for an audit, audit first, then rewrite.

If the user asks for a carousel, use 7-slide Marcatching structure:

1. Hook.
2. Context.
3. Tension.
4. Breakdown.
5. Example or proof.
6. Insight.
7. CTA.

## Step 7: Evaluate With Quality Gates

Before giving final output, evaluate internally using the Marcatching Quality Gates:

1. Audience clarity.
2. Emotional precision.
3. Funnel relevance.
4. Specificity.
5. Cognitive ease.
6. Marcatching tone.
7. Non-generic test.
8. Ethical persuasion.
9. Action logic.
10. Save-worthy value.

If the output fails any critical gate, rewrite it before finalizing.

## Step 8: Finalize With Copywriting Skill

Final copy must be polished using `skill.copywritting-marcatching.md`.

This means:

- Remove generic AI language.
- Compress sentences.
- Strengthen punchlines.
- Add psychological precision.
- Maintain premium restraint.
- Use Indonesian as the main language.
- Use English only for punchlines, frameworks, or signature statements.
- Keep CTA elegant and logical.
- Avoid hype, fake scarcity, manipulation, and overclaiming.

# 7. Category Routing Rules

## 7.1 Trust

Use when the audience needs to feel safe, convinced, and less skeptical.

Must include:

- Trust barrier.
- Perceived risk.
- Proof or credibility.
- Risk reduction.
- Clear next step.

Never do:

- Say “trusted” without proof.
- Overclaim.
- Push for conversion too early.
- Hide limitations.

Default output logic:

```text
Trust barrier → proof → clarity → reassurance → natural CTA
```

Quality question:

**Does this make the audience feel safer to continue?**

---

## 7.2 Urgency

Use when the audience needs a reason to act now.

Must include:

- Legitimate urgency source.
- Real deadline or real limitation if available.
- Opportunity cost.
- Consequence of delay.
- Ethical CTA.

Never do:

- Fake scarcity.
- Panic language.
- “Buruan” as default.
- Deadline claims without basis.

Default output logic:

```text
Delay diagnosis → timing relevance → opportunity cost → action now → ethical CTA
```

Quality question:

**Does this create action without manipulation?**

---

## 7.3 Premium Perception

Use when the product needs to feel more valuable, refined, or high-status.

Must include:

- Perceived value source.
- Specific detail.
- Restraint.
- Identity signal.
- Price sensitivity reduction.

Never do:

- Shout.
- Overuse adjectives.
- Lead with discount.
- Say “premium” too much.
- Make the product sound expensive without proof.

Default output logic:

```text
Value detail → refined framing → identity signal → confident CTA
```

Quality question:

**Does this feel expensive without saying expensive?**

---

## 7.4 Identity Signaling

Use when the product, content, or action should represent who the audience is or wants to become.

Must include:

- Desired self.
- Current identity tension.
- Identity signal.
- Aspirational but believable framing.
- Symbolic meaning.

Never do:

- Shame the audience.
- Sound arrogant.
- Create superiority in a cheap way.
- Overstate status.

Default output logic:

```text
Current self → desired self → signal → identity shift → CTA
```

Quality question:

**Would the audience share this because it represents them?**

---

## 7.5 Loss Aversion

Use when the audience needs to see the cost of staying the same.

Must include:

- Hidden cost.
- Old behavior risk.
- Opportunity loss.
- Ethical risk framing.
- Path forward.

Never do:

- Fearmongering.
- Invent risks.
- Make the audience feel stupid.
- Leave the audience anxious without solution.

Default output logic:

```text
Old behavior → hidden cost → risk awareness → better path → CTA
```

Quality question:

**Does this reveal a real loss without creating panic?**

---

## 7.6 Cognitive Ease

Use when the message needs to be easier to understand, process, remember, or trust.

Must include:

- Main idea.
- Message hierarchy.
- Simplification.
- Clear structure.
- Short sentences.

Never do:

- Oversimplify until inaccurate.
- Remove important nuance.
- Use unnecessary jargon.
- Make copy feel basic.

Default output logic:

```text
Complex idea → simplified hierarchy → clear explanation → memorable takeaway
```

Quality question:

**Can the audience understand this in one read?**

---

## 7.7 Belonging

Use when the audience needs to feel part of a group, standard, or movement.

Must include:

- Shared belief.
- Shared frustration.
- Shared standard.
- Inclusive tone.
- Invitation.

Never do:

- Create cult-like language.
- Mock outsiders.
- Force community feeling.
- Use cheap engagement bait.

Default output logic:

```text
Shared frustration → shared belief → shared standard → invitation
```

Quality question:

**Does this make the audience feel seen and represented?**

---

## 7.8 Relief

Use when the audience feels overwhelmed, confused, anxious, or behind.

Must include:

- Validation.
- Simplification.
- First step.
- Reassurance.
- Clarity.

Never do:

- Shame the audience.
- Make the issue sound too easy if it is not.
- Remove direction.
- Become too soft without action.

Default output logic:

```text
Validate overwhelm → simplify problem → give first step → reassuring CTA
```

Quality question:

**Does this make the problem feel lighter and more actionable?**

# 6. Marcatching Voice and Tone

## 6.1 Voice Personality

Marcatching sounds like a calm strategist with taste.

It is:

- Sharp.
- Calm.
- Elegant.
- Clear.
- Intelligent.
- Premium.
- Observant.
- Slightly mysterious.
- Quietly confident.
- Emotionally precise.

It is not:

- Loud.
- Hype-heavy.
- Overly cheerful.
- Overly motivational.
- Too academic.
- Too rigid.
- Too salesy.
- Too slang-heavy.
- Too generic.

## 6.2 Language Style

Use Indonesian as the main language.

Use English only for:

- Punchlines.
- Short framing lines.
- Signature concepts.
- Hooks.
- High-impact contrast.

Good examples:

- “Most prompts ask AI to write. Strategic prompts ask AI to think.”
- “The best content does not explain harder. It removes friction.”
- “Trust is not claimed. Trust is designed.”
- “A prompt is not a request. It is a thinking system.”

Avoid English that sounds too corporate or too generic.

## 6.3 Sentence Rhythm

Marcatching copy should feel controlled.

Use:

- Short sentences.
- Clear hierarchy.
- One idea per paragraph.
- Strong contrast.
- Minimal adjectives.
- Specific words.
- Clean transitions.

Avoid:

- Long crowded paragraphs.
- Too many buzzwords in one sentence.
- Excessive explanation.
- “AI banget” generic phrasing.
- Empty inspirational lines.

## 6.4 Tone Formula

A Marcatching output should feel like this:

**Smart enough to feel premium. Clear enough to feel useful. Emotional enough to feel human.**

# 7. Prompt Engineering Principles For This Skill

This section adapts current best practices for prompting large language models into Marcatching’s internal copywriting workflow.

## 7.1 Be Clear And Specific

Every prompt must clearly specify:

- Role.
- Objective.
- Audience.
- Context.
- Product or offer.
- Emotional lever.
- Channel.
- Output format.
- Tone.
- Constraints.
- Examples when available.

Weak:

> Buatkan copy untuk course AI marketing.

Strong:

> Kamu adalah Marcatching marketing strategist. Buat copy carousel 7 slide untuk course AI marketing dengan target founder muda dan content creator yang merasa tertinggal oleh AI. Gunakan emotional lever relief dan control. Tone harus smart, calm, premium, dan tidak hard-selling. Output harus berisi hook, context, tension, insight, proof angle, takeaway, dan CTA.

## 7.2 Put Instructions Before Context

For complex requests, put the task first, then context.

Recommended structure:

1. Role.
2. Task.
3. Required workflow.
4. Output format.
5. Constraints.
6. Context.
7. Input data.

This makes the model understand what to do before reading the material.

## 7.3 Use Clear Separators

Use Markdown headings, XML-style tags, or labels to separate input sections.

Example:

```text
# Role
You are a Marcatching copy strategist.

# Task
Create 10 prompt templates for trust-building copy.

# Context
<product>
...
</product>

<audience>
...
</audience>

# Output Format
Return a table with: Prompt Name, Use Case, Emotional Lever, Full Prompt, Best For, Avoid When.
```

## 7.4 Ask For Output Format Explicitly

Never assume the model knows the desired shape.

Specify whether the output should be:

- Table.
- Bullet list.
- Carousel slides.
- Caption.
- Script.
- Framework.
- Prompt pack.
- Audit report.
- Before-after comparison.
- JSON-like structure.
- Markdown guide.

Example:

> Output dalam tabel dengan 6 kolom: Category, Psychological Job, Use Case, Master Prompt, Variations, Quality Check.

## 7.5 Use Examples To Teach Taste

When a desired style is specific, provide examples.

Example:

Bad style:

> “Yuk buruan join kelas AI marketing supaya bisnismu makin cuan!”

Marcatching style:

> “Kamu tidak butuh lebih banyak tools. Kamu butuh cara berpikir yang membuat AI bekerja untuk strategimu.”

Examples reduce ambiguity and help preserve brand tone.

## 7.6 Iterate Instead Of Expecting Perfection

Prompting is a workflow, not a single command.

Recommended iteration loop:

1. Generate first output.
2. Evaluate against Marcatching quality gates.
3. Identify what feels generic.
4. Rewrite with sharper audience psychology.
5. Compress and polish.
6. Produce final version.

## 7.7 Break Complex Tasks Into Stages

For deep marketing work, do not ask AI to jump directly to final copy.

Use this sequence:

1. Analyze audience.
2. Identify emotional state.
3. Choose psychological lever.
4. Map friction.
5. Create angle options.
6. Write copy.
7. Evaluate copy.
8. Rewrite final.

This is the Marcatching way.

## 7.8 Give The Model Relevant Context

Good copy depends on context.

Always include:

- Product details.
- Audience details.
- Brand tone.
- Price point if relevant.
- Stage of funnel.
- Platform.
- Offer.
- Proof or credibility.
- Objections.
- Desired action.

If context is missing, infer carefully and state assumptions only when needed.

## 7.9 Prefer Positive Instructions

Instead of only saying what not to do, tell the model what to do instead.

Weak:

> Jangan lebay. Jangan hard selling. Jangan AI banget.

Strong:

> Tulis dengan tone calm, sharp, dan premium. Gunakan klaim yang spesifik, kalimat pendek, dan CTA yang terasa seperti langkah logis berikutnya. Hindari diskon sebagai angle utama.

## 7.10 Use Evaluation Criteria

Every strong prompt needs a built-in evaluation system.

Ask the model to check:

- Is the audience clear?
- Is the emotional lever clear?
- Is the message specific?
- Is the copy easy to process?
- Is the CTA natural?
- Does it feel Marcatching?
- Does it avoid generic AI language?

# 9. Audience OS

Audience OS is Marcatching’s core thinking framework.

Before writing copy, always map the audience through six layers.

## 9.1 Pain

What problem do they consciously feel?

Questions:

- What frustrates them?
- What do they complain about?
- What feels difficult?
- What is not working for them?

Example:

> “Aku sudah pakai AI, tapi hasil copy-nya tetap generic.”

## 9.2 Desire

What emotional outcome do they want?

Questions:

- What do they want to feel?
- What version of themselves do they want to become?
- What progress do they want to see?

Example:

> “Aku ingin merasa punya sistem dan bisa memakai AI dengan percaya diri.”

## 9.3 Fear

What are they afraid will happen if they do nothing?

Questions:

- What do they fear losing?
- What makes them anxious?
- What future do they want to avoid?

Example:

> “Aku takut tertinggal dari marketer lain yang sudah lebih cepat pakai AI.”

## 9.4 Status

What identity do they want to signal?

Questions:

- Who do they want to be seen as?
- What identity would make them proud?
- What signal do they want to send?

Example:

> “Aku bukan sekadar content creator. Aku strategic creator.”

## 9.5 Friction

What blocks them from acting?

Questions:

- What confuses them?
- What feels risky?
- What is too hard?
- What do they not believe yet?

Example:

> “Terlalu banyak tools dan aku tidak tahu prompt yang benar.”

## 9.6 Trigger

What event makes them ready to act now?

Questions:

- What moment creates urgency?
- What recent problem makes the pain visible?
- What makes them look for a solution today?

Example:

> “Konten viral, tapi tidak ada yang beli.”

# 21. Prompt Diagnosis System

Use this when evaluating bad prompts.

## 21.1 The Five Prompt Failures

### 1. No Audience Context

The prompt does not define who the copy is for.

Fix:

Add demographic, psychographic, pain, desire, fear, status, and friction.

### 2. No Emotional Direction

The prompt does not define what the audience should feel.

Fix:

Choose one dominant lever: trust, urgency, premium, identity, loss aversion, cognitive ease, belonging, or relief.

### 3. No Strategic Objective

The prompt does not define what the copy must achieve.

Fix:

Define funnel stage and desired action.

### 4. No Psychological Mechanism

The prompt only asks for output, not reasoning.

Fix:

Ask for diagnosis first, copy second.

### 5. No Brand Voice

The prompt does not define tone, style, and constraints.

Fix:

Add Marcatching tone rules.

## 21.2 Prompt Rewrite Formula

```text
Weak prompt:
[insert weak prompt]

Diagnosis:
- Missing audience:
- Missing emotional lever:
- Missing funnel stage:
- Missing proof:
- Missing tone:

Strategic prompt:
[rewrite prompt using Marcatching Prompt Stack]

Expected improvement:
[explain why the new prompt will produce better output]
```

# 22. Marcatching Quality Gates

Before finalizing any output, check it against these gates.

## Gate 1: Audience Clarity

Can we clearly see who this is for?

If not, rewrite.

## Gate 2: Emotional Precision

Is there one dominant emotional lever?

If not, choose one.

## Gate 3: Strategic Relevance

Does the copy match the funnel stage?

If not, adjust.

## Gate 4: Specificity

Is there enough detail to feel credible?

If not, add concrete proof, context, or example.

## Gate 5: Cognitive Ease

Can the audience understand it in one read?

If not, simplify.

## Gate 6: Marcatching Tone

Does it feel sharp, calm, premium, and intelligent?

If not, polish.

## Gate 7: Non-Generic Test

Would this sound like any AI account could have written it?

If yes, add a sharper insight or unique framing.

## Gate 8: Ethical Persuasion

Is the copy persuasive without manipulation?

If not, remove fake scarcity, excessive fear, or unsupported claims.

## Gate 9: Action Logic

Does the CTA feel like the natural next step?

If not, reframe.

## Gate 10: Save-Worthy Test

Would someone save this because it gives them a usable thinking tool?

If not, add framework, checklist, prompt, example, or template.

# 23. Editing Rules

## 23.1 Remove Empty Phrases

Avoid:

- “Di era digital saat ini.”
- “Seperti yang kita ketahui.”
- “Sangat penting sekali.”
- “Meningkatkan engagement secara maksimal.”
- “Solusi terbaik untuk bisnis Anda.”
- “Jangan sampai ketinggalan.”
- “Yuk buruan.”

Replace with sharper language:

- “Tools berubah. Tapi keputusan manusia tetap punya pola.”
- “Masalahnya bukan kurang konten. Masalahnya konten tidak punya sistem.”
- “AI mempercepat output. Psychology memperbaiki arah.”

## 23.2 Use Contrast

Good Marcatching copy often uses contrast.

Examples:

- “Bukan lebih banyak tools. Lebih jelas cara berpikir.”
- “Bukan caption yang lebih panjang. Message yang lebih tepat.”
- “Bukan AI yang kurang pintar. Input-nya yang kurang strategic.”
- “Bukan jualan lebih keras. Mengurangi friction lebih baik.”

## 23.3 Use Concrete Words

Prefer:

- Friction.
- Trust.
- Desire.
- Signal.
- Perception.
- Decision.
- Attention.
- System.
- Trigger.
- Proof.
- Clarity.
- Identity.

Avoid vague words:

- Powerful.
- Amazing.
- Maksimal.
- Luar biasa.
- Spektakuler.
- Terbaik.
- Super lengkap.

## 23.4 Keep The Punchline Clean

A punchline should be short enough to remember.

Examples:

- “Bad prompts create words. Strategic prompts create decisions.”
- “Trust is not claimed. Trust is designed.”
- “The prompt is not the skill. Thinking is.”
- “AI can write the copy. It cannot fix unclear strategy.”
- “More content is not a strategy. Better friction design is.”

# 33. Ethical Standards

Marcatching persuasion must be ethical.

## 33.1 Do Not Use Fake Scarcity

Never create urgency from false limitations.

Bad:

> “Slot tinggal 3” when there is no real limit.

Good:

> “Early access closes tonight because the first cohort starts tomorrow.”

## 33.2 Do Not Exaggerate Proof

Do not invent:

- Revenue.
- Testimonials.
- User counts.
- Case studies.
- Expert endorsements.
- Certifications.

If proof is unavailable, use logical proof or process transparency.

## 33.3 Do Not Shame The Audience

Avoid making people feel stupid for not knowing something.

Bad:

> “Kalau kamu belum pakai AI, kamu ketinggalan banget.”

Better:

> “AI bergerak cepat. Tapi kamu tidak perlu mengejar semua tools. Mulai dari sistem berpikirnya.”

## 33.4 Do Not Overuse Fear

Fear can create attention, but too much fear destroys trust.

Use risk awareness, not panic.

## 33.5 Always Separate Fact And Opinion

If making a factual claim, verify it.

If giving a strategic opinion, frame it as Marcatching’s point of view.

# Category 1: Prompt for Trust

## Psychological Job
Trust prompt dipakai untuk mengurangi perceived risk. Tujuannya bukan membuat audiens langsung membeli, tetapi membuat mereka merasa cukup aman untuk lanjut membaca, klik, daftar, bertanya, atau mempertimbangkan.

Trust tidak dibangun dengan kata “terpercaya”. Trust dibangun lewat specificity, proof, clarity, process transparency, honest limitation, risk reduction, dan tone yang tenang.

# 3. The Big Framework: Audience OS

## 3.1 Framework Name

**Audience OS**

Audience OS adalah framework utama Marcatching untuk menggunakan AI dalam membaca audiens sebelum membuat konten, copy, ads, landing page, atau funnel.

OS berarti operating system. Artinya, sebelum AI diminta menulis, AI harus diberi sistem berpikir.

## 3.2 The Six Layers of Audience OS

### 1. Pain

Apa masalah nyata yang sedang dirasakan audiens?

Bukan masalah di permukaan, tetapi masalah yang cukup mengganggu untuk membuat mereka mencari solusi.

Contoh:

- “Aku bingung kenapa kontenku tidak convert.”
- “Aku sudah posting tiap hari, tapi tidak ada yang beli.”
- “Aku merasa kalah cepat dari orang yang sudah pakai AI.”

### 2. Desire

Apa hasil emosional yang mereka inginkan?

Desire bukan hanya output praktis. Sering kali desire adalah rasa.

Contoh:

- Ingin merasa lebih percaya diri.
- Ingin terlihat lebih strategic.
- Ingin punya sistem yang jelas.
- Ingin merasa tidak tertinggal.

### 3. Fear

Apa yang mereka takutkan jika tidak berubah?

Fear bukan untuk menakut-nakuti secara murahan, tetapi untuk memahami risiko psikologis yang mereka rasakan.

Contoh:

- Takut digantikan AI.
- Takut bisnis tertinggal.
- Takut kontennya makin tidak relevan.
- Takut terlihat amatir.

### 4. Status

Identitas apa yang ingin mereka tampilkan?

Orang tidak hanya membeli produk. Mereka membeli versi diri yang ingin mereka percaya.

Contoh:

- “Aku marketer yang adaptif.”
- “Aku founder yang punya sistem.”
- “Aku content creator yang ngerti strategy.”
- “Aku bukan sekadar ikut tren AI.”

### 5. Friction

Apa yang menghalangi mereka untuk bergerak?

Friction bisa berupa kebingungan, rasa malas, kurang percaya, terlalu banyak pilihan, atau tidak tahu harus mulai dari mana.

Contoh:

- Terlalu banyak tools.
- Tidak tahu prompt yang benar.
- Takut output AI jadi generik.
- Tidak punya framework.

### 6. Trigger

Apa pemicu yang membuat mereka akhirnya mengambil tindakan?

Trigger adalah momen saat masalah terasa cukup dekat, jelas, dan mendesak.

Contoh:

- Melihat kompetitor lebih cepat produksi konten.
- Ads tidak convert.
- Launching gagal.
- Konten viral tapi tidak menghasilkan sales.
- Merasa tertinggal dari perkembangan AI.

# 6. Signature Idea C: The Prompt Clinic

## 6.1 Concept

**Send us your prompt. We’ll diagnose why it does not work.**

The Prompt Clinic adalah format konten yang membedah prompt audience, lalu menjelaskan mengapa prompt tersebut menghasilkan output generik.

Ini bukan sekadar memperbaiki prompt. Ini mengajarkan cara berpikir.

## 6.2 Why It Works

Format ini punya potensi viral karena:

- Ada unsur diagnosis.
- Ada before-after.
- Ada edukasi praktis.
- Ada rasa “wah, ternyata selama ini prompt gue salah.”
- Audience terdorong untuk submit prompt mereka.

## 6.3 Diagnosis Framework

Setiap prompt dibedah menggunakan 5 diagnosis:

### 1. No Audience Context

Prompt tidak menjelaskan siapa audiensnya.

### 2. No Emotional Direction

Prompt tidak menjelaskan emosi apa yang ingin dipicu.

### 3. No Strategic Objective

Prompt tidak jelas ingin awareness, trust, conversion, retention, atau engagement.

### 4. No Psychological Lever

Prompt tidak memakai leverage seperti loss aversion, status, social proof, cognitive ease, atau urgency.

### 5. No Brand Voice

Prompt tidak menjelaskan tone, positioning, dan batasan gaya bahasa.

## 6.4 Content Structure

Carousel:

1. Hook: “This prompt looks fine. That’s the problem.”
2. Show original prompt.
3. Diagnosis.
4. What is missing psychologically.
5. Rewritten strategic prompt.
6. Output comparison.
7. CTA: “Drop your prompt. We’ll diagnose the next one.”

Reels:

1. “Prompt kamu bukan jelek. Prompt kamu buta audiens.”
2. Baca prompt original.
3. Tunjukkan masalahnya.
4. Rewrite.
5. Compare output.

## 6.5 Example

Original prompt:

> Buatkan caption jualan parfum.

Diagnosis:

Prompt ini terlalu luas. Tidak ada audience, tidak ada desire, tidak ada identity, tidak ada buying trigger.

Strategic prompt:

> Buatkan caption untuk parfum lokal premium dengan target perempuan usia 22-30 tahun yang ingin terlihat elegan, mature, dan memorable tanpa terlihat berusaha terlalu keras. Gunakan emotional lever identity signaling dan subtle desire. Hindari hard selling dan diskon. Tone harus calm, sensual, dan premium.

## 8.1 Concept

## 8.2 Emotional Categories

### 1. Trust

Untuk membuat audience merasa aman, percaya, dan yakin.

Use cases:

- Landing page.
- Testimonial section.
- About page.
- Product explanation.
- Educational content.

Prompt example:

> Buat copy untuk membangun trust terhadap produk berikut. Fokus pada detail spesifik, proof, risk reversal, dan clarity. Hindari klaim berlebihan. Buat audience merasa aman untuk mengambil langkah berikutnya.

### 2. Urgency

Untuk membuat audience merasa perlu bergerak sekarang.

Prompt example:

> Buat copy dengan urgency yang legitimate. Jangan gunakan fake scarcity. Tekankan opportunity cost, timing, dan risiko jika audience menunda keputusan.

### 3. Premium Perception

Untuk membuat produk terasa lebih berkelas tanpa terlihat sombong.

Prompt example:

> Buat copy yang meningkatkan premium perception produk berikut. Gunakan tone calm, minimal, confident, dan refined. Hindari diskon, klaim berisik, dan kata-kata murahan.

### 4. Identity Signaling

Untuk membuat produk terasa seperti simbol identitas.

Prompt example:

> Buat campaign angle yang menjadikan produk ini sebagai identity signal. Fokus pada siapa audience ingin menjadi ketika memakai produk ini, bukan hanya apa fitur produknya.

### 5. Loss Aversion

Untuk menunjukkan apa yang hilang jika audience diam saja.

Prompt example:

> Buat copy berdasarkan loss aversion. Tekankan risiko tersembunyi, opportunity loss, dan konsekuensi jika audience tetap memakai cara lama. Jangan menakut-nakuti berlebihan.

### 6. Cognitive Ease

Untuk membuat pesan lebih mudah dipahami dan dipercaya.

Prompt example:

> Sederhanakan copy berikut agar lebih mudah diproses, lebih jelas, dan lebih credible. Gunakan kalimat pendek, struktur rapi, dan message hierarchy yang clean.

### 7. Belonging

Untuk membuat audience merasa menjadi bagian dari kelompok tertentu.

Prompt example:

> Buat copy yang membangun rasa belonging untuk audience berikut. Gunakan framing “people like us do things like this” tanpa terdengar eksklusif secara berlebihan.

### 8. Relief
